<objective>
Fix FIX-04 and FIX-03 for am-dialog, reusing the TeardownScope discipline proven by the plan 03-01 tracer.

FIX-04: `_nudge()` (dialog.ts ~217-225) adds an `animationend` listener on the shadow `<dialog>` each time it fires, and am-dialog has NO `disconnectedCallback` — so a dialog disconnected mid-nudge dangles that listener. Add a `disconnectedCallback` that clears a `TeardownScope`, and route the nudge listener through the scope's `signal`.

FIX-03: `_hide()` (dialog.ts ~194-200) restores focus guarded only by `instanceof HTMLElement`. If the opener was removed while the dialog was open, `focus()` is called on a disconnected node. Add an `isConnected` guard so closing a dialog whose opener was removed does not attempt to focus the disconnected node (and never throws).

Purpose: dialog animation listeners never dangle (FIX-04); focus restoration is safe when the opener is gone (FIX-03).
Output: hardened dialog.ts + jsdom tests + the existing browser finding test flipped from "unguarded finding" to "guarded fix".
</objective>

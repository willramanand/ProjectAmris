<objective>
Publish per-component cost cards (measured brotli size + runtime count cost per component) as a committed, drift-gated `docs/cost-cards.md` so enterprise consumers can budget (DOCS-04). Zero new dependencies: a new `scripts/build-cost-cards.mjs` mirrors the proven `scripts/build-contract-doc.mjs` generator and reads the already-committed `api/*.baseline.json` measured numbers; CI regenerates and `git diff`-gates the doc exactly like `docs/contract.md`.

Purpose: Make the banked size/runtime gains visible and budgetable without re-measuring, and keep the published numbers provably in sync with the enforced baselines.
Output: `scripts/build-cost-cards.mjs`, generated `docs/cost-cards.md`, a `build:cost-cards` npm script, a unit test, and a CI drift-check step.
</objective>

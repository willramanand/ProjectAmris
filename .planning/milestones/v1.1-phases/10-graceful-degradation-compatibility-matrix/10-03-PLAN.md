(grep-confirmed) — nothing to guard there, but the "guard every usage" rule
stands if one is ever added.

selector is dropped (not thrown) and a component renders in a subtly wrong
state on old engines, without introducing any JS-driven visual coupling.

guard-shape assertion test, and a browser-lane regression spec proving
above-floor behavior is unchanged.
</objective>

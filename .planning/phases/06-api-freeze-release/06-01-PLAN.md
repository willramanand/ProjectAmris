| packed tarball → consumer project | Only the `files` allowlist is shipped; the `exports` map must resolve to real shipped files. |
| smoke temp project → registries | The Lit peer installs from public npm; the `@willramanand` scope stays pinned to GitHub Packages and no publish token is used. |

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `exports` map → consumer imports | Every documented deep entry must resolve to a real shipped file; a broken entry ships a package that fails on install. |
| `sideEffects` → tree-shaking | Only element-registration + CSS modules may be side-effectful; over-listing bloats every consumer, under-listing drops registration/styles. |
| PR-triggered CI → credentials | The smoke job runs on a read-only workflow and must never receive a publish token. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04 | Tampering | package.json exports/sideEffects | high | mitigate | Smoke matrix resolves every entry from an installed tarball; size canary proves tree-shaking still holds after the sideEffects change. |
| T-06-05 | Information disclosure | npm pack tarball | medium | mitigate | `files` stays `["dist","README.md"]`; no `.npmignore` widens it; the smoke installs only the packed tarball + public `lit`. |
| T-06-06 | Elevation of privilege | CI smoke job | medium | mitigate | Job inherits `permissions: contents: read`; no `packages: write`, no secrets, no publish step in the PR pipeline. |
| T-06-SC | Tampering | dependencies | low | accept | No new package-manager dependencies; bundler leg reuses repo-resident esbuild; Lit stays an unbundled peer. |
</threat_model>

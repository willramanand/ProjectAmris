## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| consumer/server code → `setCustomError(message)` | Attacker-influenced server error strings cross into the control and are rendered into the DOM |
| native constraint engine → `validationMessage` | Browser-generated message text rendered into the DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering / Info-disclosure | ValidationController message render | high | mitigate | Message rendered via Lit `${}` text binding only; no raw-HTML sink introduced (ASVS V5). Browser test asserts the rendered node is text, not markup. |
| T-04-02 | Tampering | am-input aria-describedby target id | low | accept | id is generated by the internal uniqueId utility, not consumer-controlled; collision-free per existing utility contract. |
| T-04-03 | Repudiation | invalid-state reflection | low | accept | Validity is derived from native ElementInternals; no independent trust store. |
</threat_model>
